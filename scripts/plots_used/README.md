# Scripts Used for Report Figures

This directory contains the Python plotting scripts that generate the figures used in the REPORT.md document.

## Quick Start: Jupyter Notebook

**Recommended approach**: Use the Jupyter notebook to generate all figures at once:

```bash
cd /path/to/HPCC
jupyter notebook scripts/plots_used/generate_report_figures.ipynb
```

The notebook (`generate_report_figures.ipynb`) provides an elegant interface to generate all report figures:
- OpenMP Scaling (speedup and efficiency)
- Strong Scaling (speedup/efficiency and execution time breakdown)
- Weak Scaling (efficiency and execution time breakdown)

Simply run all cells to generate all figures in the `figures/` directory.

## Individual Scripts

Alternatively, you can run individual scripts from the project root:

```bash
cd /path/to/HPCC
python3 scripts/plots_used/plot_*.py
```

### OpenMP Scaling
- **plot_omp_speedup.py** - Generates `omp_speedup.png` (Figure 1)
- **plot_omp_efficiency.py** - Generates `omp_efficiency.png` (Figure 2)

### Strong Scaling
- **plot_strong_speedup_efficiency.py** - Generates `strong_speedup_efficiency.png` (Figure 3)
- **plot_strong_execution_time.py** - Generates `strong_execution_time.png` (Figure 5)

### Weak Scaling
- **plot_weak_scaling.py** - Generates `weak_efficiency.png` (Figure 7)
  - Uses: `data/SM3800083_weak_parallel_results_corrected.csv`
- **plot_weak_execution_time.py** - Generates `weak_execution_time.png` (Figure 8)
  - Uses: `data/SM3800083_weak_parallel_results_corrected.csv`

Output figures are saved to `figures/` directory.

## Note

The `build_variant_comparison.png` figure (Figure 9) is generated by a script located elsewhere or created manually.
