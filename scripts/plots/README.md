# Report Figures Generator

This directory contains the Python plotting scripts and Jupyter notebook that generate all figures used in the REPORT.md document.

## Quick Start: Jupyter Notebook (Recommended)

**Best approach**: Use the comprehensive Jupyter notebook to generate all figures and perform statistical analysis:

```bash
cd /path/to/HPCC
jupyter notebook scripts/plots/generate_report_figures.ipynb
```

The notebook (`generate_report_figures.ipynb`) provides:

### Figure Generation
- **OpenMP Scaling**: `omp_speedup.png`, `omp_efficiency.png`
- **OpenMP Code Optimization Impact**: `omp_build_variant_comparison.png` (ofast vs ofast_omp_improved)
- **Strong Scaling**: `strong_speedup_efficiency.png`, `strong_execution_time.png`
- **Weak Scaling**: `weak_efficiency.png`, `weak_execution_time.png`

### Comprehensive Analysis
- **Measurement Quality Analysis**: Statistical analysis of measurement reliability (CV, percent difference)
- **Performance Metrics Summary**: Speedup, efficiency, and runtime comparisons
- **Communication Overhead Analysis**: Detailed breakdown of MPI communication costs

Simply run all cells to generate all figures and obtain detailed statistical insights. All figures are saved to the `figures/` directory.

## Individual Scripts

Alternatively, you can run individual plotting scripts from the project root:

```bash
cd /path/to/HPCC
python3 scripts/plots/plot_*.py
```

### OpenMP Scaling
- **plot_omp_speedup.py** - Generates `omp_speedup.png` (Figure 1)
- **plot_omp_efficiency.py** - Generates `omp_efficiency.png` (Figure 2)
- **plot_omp_build_variant_comparison.py** - Generates `omp_build_variant_comparison.png` (Figure 9)
  - Compares `ofast` vs `ofast_omp_improved` (identical compiler flags, different OpenMP pragmas)
  - Demonstrates the critical importance of explicit OpenMP pragmas in the code

### Strong Scaling
- **plot_strong_speedup_efficiency.py** - Generates `strong_speedup_efficiency.png` (Figure 3)
- **plot_strong_execution_time.py** - Generates `strong_execution_time.png` (Figure 5)

### Weak Scaling
- **plot_weak_scaling.py** - Generates `weak_efficiency.png` (Figure 7)
  - Uses: `data/SM3800083_weak_parallel_results_corrected.csv`
  - Shows both periodic and non-periodic boundary conditions
- **plot_weak_execution_time.py** - Generates `weak_execution_time.png` (Figure 8)
  - Uses: `data/SM3800083_weak_parallel_results_corrected.csv`
  - Breakdown of communication vs total time for both boundary conditions

## Data Sources

The scripts use the following CSV files from the `data/` directory:
- `SM3800083_omp_serial_results.csv` - OpenMP scaling data
- `SM3800083_strong_parallel_results.csv` - Strong scaling data
- `SM3800083_weak_parallel_results_corrected.csv` - Weak scaling data (corrected version with proportional grid scaling)

## Output

All figures are saved to the `figures/` directory with 300 DPI resolution suitable for publication.

## Note

The `omp_build_variant_comparison.png` figure (Figure 9) is generated by `plot_omp_build_variant_comparison.py` and shows the impact of OpenMP code optimizations (pragmas) rather than compiler optimizations. It compares two code variants with identical compiler flags but different OpenMP parallelization.
